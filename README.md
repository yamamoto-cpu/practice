# practice

## Overview
This project is a small fortune-telling website. When you open the page you will be asked for your name and given a random result.

## Usage
Open `index.html` in your web browser to see the result. You can double-click the file or use your browser's "Open File" option.

## Requirements
A modern web browser capable of running basic JavaScript is all you need.
